# PAS.MarketData.Client

An autogenerated C# API Client for consuming **PAS.MarketData.Api**, built using [Microsoft Kiota](https://learn.microsoft.com/en-us/openapi/kiota/).

## Prerequisites

Before regenerating or updating the client code, ensure you have the Kiota CLI installed globally:
```
dotnet tool install -g Microsoft.OpenApi.Kiota
```

## First generation

To regenerate the client for the first time:
- Run the PAS.MarketData API locally.
- Open a PowerShell prompt in the `src/MarketData/Client` folder.
- Execute the following command if the api is currently running:
``` 
kiota generate -l cSharp -c MarketDataApiClient -n PAS.MarketData.Client -d https://localhost:7116/openapi/v1.json -o .
```
- Or execute the following command if api was compiled (and openapi.json was generated):
``` 
kiota generate -l cSharp -c MarketDataApiClient -n PAS.MarketData.Client -d ../Api/openapi.json -o .
```

## Regenerating

To regenerate the client:
- Run the PAS.MarketData API locally.
- Open a PowerShell prompt in the `src/MarketData/Client` folder.
- Execute the following command:
```
kiota update -o .
```
